# Proyecto - Codificación de Huffman

## Objetivos

Los objetivos del proyecto son principalmente la aplicación de las técnicas de
programación vistas durante el laboratorio hacia un caso de uso práctico, así
como la investigación e implementación de la codificación de Huffman.

## Funcionamiento

Para hacer uso del proyecto y las funciones en él contenidas, usamos:

```bash
ghci Proyecto.hs
```

Una vez cargado el ambiente podemos realizar la ejecución de cada parte de
acuerdo a las instrucciones contenidas en el reporte del proyecto.

## Tiempo Requerido

1 semana.
